---------------------------------------------------------------------------------------------------------------------------
1.1 Migrations
php artisan make:migration create_roles_table --create=roles
php artisan make:migration create_role_user_table --create=role_user
php artisan make:migration create_requisicoes_table --create=requisicoes
php artisan make:migration add_disponivel_to_livros_table --table=livros


O que fazem

create_roles_table → cria tabela roles (nome da role, slug).

create_role_user_table → pivot role_user para associar users⇄roles.

create_requisicoes_table → tabela de requisições (todos os campos do fluxo).

add_disponivel_to_livros_table → adiciona boolean disponivel à tabela de livros (se ainda não houver).

1.2 Models
php artisan make:model Role
php artisan make:model Requisicao


O que fazem

Criam os modelos Eloquent. Vais adicionar relações (users(), livros(), etc.) nesses ficheiros.

1.3 Controllers (CRUD / lógica)
php artisan make:controller RequisicaoController --resource
php artisan make:controller Admin/UserController
php artisan make:controller LivroController --resource   # se ainda precisares do CRUD server-side


O que fazem

RequisicaoController → index/store/show/update/destroy para requisições.

Admin/UserController → para promover utilizadores (criação de admins).

LivroController → (opcional) gerir livros no backend (Admin).

1.4 Requests, Policy, Mail, Notification, Seeder
php artisan make:request RequisicaoStoreRequest
php artisan make:policy RequisicaoPolicy --model=Requisicao
php artisan make:seeder RoleSeeder
php artisan make:seeder AdminSeeder
php artisan make:seeder LivroSeeder
php artisan make:mail RequisicaoCreatedMail
php artisan make:notification RequisicaoReminderNotification


O que fazem

RequisicaoStoreRequest → validação da criação de requisições.

RequisicaoPolicy → controla quem pode ver/criar/confirmar requisições.

RoleSeeder + AdminSeeder + LivroSeeder → popular DB.

RequisicaoCreatedMail → e-mail de confirmação.

RequisicaoReminderNotification → notificação/email para reminder do dia anterior.

1.5 (Opcional) Job / Command para Reminders
php artisan make:job SendRequisitionReminderJob
php artisan make:command SendDailyRequisitionReminders


Usados no scheduler (app/Console/Kernel.php) para enviar reminders automáticos.
